# X2100 + Cheetah4401M 4TX4RX Walsh-BPM 软件候选版

该版本与现有 2TX4RX 实时版、回放版及 4TX4RX-DDMA 框架版相互独立。

## 已实现

- 使用 4x4 Walsh-Hadamard 二进制正交矩阵：
  - `++++`
  - `+-+-`
  - `++--`
  - `+--+`
- 每个符号 `+/-` 分别代表 0/180 度相位；
- 复用现有 512-chip `bpm_code` 作为四路 TX 的公共扰码；
- Cheetah 端候选相位符号定义为
  `legacy_bpm_code[chirp] * walsh[chirp % 4][tx]`；
- 每 4 个连续 chirp 通过 `H^T/4` 解出 TX1-TX4；
- 128 个原始 chirp 转换为每 TX 32 个慢时间样本；
- 对 16 个 TX-RX 虚拟通道分别执行 32 点 Doppler FFT；
- 16 通道非相干积累后进行二维 CFAR；
- AoA 使用 16 虚拟通道和 128 点角度 FFT；
- 保留 MotorCycle Tools USB 输出。

## 速度尺度

一个 TX 慢时间采样的间隔为 `4 * 26 us = 104 us`。32 点 FFT 的速度分辨率
与旧 128 点/26 us 处理近似相同，但最大无模糊速度降为旧方案的四分之一。

## 必须验证的限制

当前 Cheetah 寄存器表仍是旧 2TX 配置。只有芯片端也让四个 TX 同时按照上述
Walsh 与公共扰码相位发射时，本固件的分离结果才有物理意义。此外仍缺少：

- 4TX 发射使能及逐 chirp 相位寄存器配置；
- 相邻 4 个 chirp 期间目标运动导致的 BPM 相位误差补偿；
- 新板 16 阵元物理位置和逻辑重排；
- 16 路幅相校准；
- CFAR 阈值实测重标定；
- 一帧真实 4TX BPM ADC 数据及参考结果。

因此该产物用于软件接口、内存、性能和协议联调，不应作为已经完成射频验证的
量产固件。
