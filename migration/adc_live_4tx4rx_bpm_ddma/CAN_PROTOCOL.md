# CAN 通信协议软件层

## 当前交付范围

实现标准数据帧（11 位 ID、DLC=8），不是 USB 虚拟串口封装。主要代码为 radar_can_protocol.h/.c。
已加入目标固件编译及启动时本地字节自检。没有自动初始化 CAN 控制器，也没有把算法点云直接发送到 CAN；原 MotorCycle USB 输出保持不变。

- 0x103/104/105：左/前/右点云批开始，24 位大端批号。
- 0x106/107/108：批结束，同批号及16位大端点数。
- 0x111/112/113：点云数据，字段逐字节打包。
- 0x101：三阵面自检结果及型号标识；需调用者提供真实结果，不能把未安装阵面填正常。
- 0x102：心跳位域；API 接受已经量化的字段，不猜测“范围”的含义。
- 0x001..005、0x011：工作模式/角度/距离/数量/周期/载机姿态解析，返回结构体。尚未接入硬件控制或输出调度。
- 0x121：升级结果报文编码接口。0x021/022 返回 UNSUPPORTED，不接收固件、不擦除或写 Flash、不自动反馈升级成功。

## 点云字段

输入采用整数协议单位，不隐式改变标定、坐标系或速度定义：

| 字节 | 内容 |
| --- | --- |
| 0 | 已标定回波强度码，0..255，0.5 dBsm/码 |
| 1 | 方位角，-45..45，1°/码，负数原码 |
| 2 | 运动方向，2°/码；本版只接受无冲突的0..127码 |
| 3 | 俯仰角，-120..120码，0.1°/码；不涉及为FF |
| 4 | 距离码高8位 |
| 5 | 高5位=距离码低5位；低3位=编号高3位 |
| 6 | 编号低8位 |
| 7 | 速度码，按signed及原码规则实现-125..125，0.5m/s/码；符号物理约定仍待对端确认 |

例如：强度码20、角度-15°、方向码45、无俯仰、距离码100（20m）、编号0x345、速度码-50，前阵面打包结果：

`112#148F2DFF032345B2`

这是人工测试向量，不是真实雷达目标。该文本是ID#数据展示方式，并非串口上发送的字符串。

## 对协议矛盾的处理

1. 全局约定负数为符号位+幅值，不使用 C 的补码强制转换；负零归一为零。
2. 距离13位最大8191码、编号11位最大2047；文档上限8192/2048无法编码，拒绝越界，不截断成0。
3. 运动方向signed8与0..180码冲突：128..180目前拒绝；不擅自改成unsigned，也不伪造方向。
4. 距离控制字标signed但范围0..255：0..127可解析，128..255返回UNSUPPORTED，等待对端明确unsigned。
5. 速度字段写signed但范围0..125。本版按全局原码规则容纳负数；正负对应接近/远离或合成速度的意义没有自行定义。
6. 方位角文字说顺时针增加，但配图方向不一致：协议层只接受调用者已经映射好的角度，没有把现有azimuth直接搬过来。
7. 心跳范围/数量/周期的量化和空值没有充分定义。尤其当前最多16点，而心跳数量单位150且最小1，不能谎报已支持150点。暂不自动生成周期性心跳。
8. CAN_1/2/3和CAN0/1/2编号不一致，协议没有给定硬件波特率；只用逻辑LEFT/FRONT/RIGHT，不硬编码总线编号和速率。

原算法power不是标定RCS，velocity_mps是径向速度，当前无跟踪速度向量。对应的应用映射不能假装已经完整。

## 批量发送接口

rcan_tx_init绑定发送回调；未绑定时rcan_send_batch返回RCAN_UNBOUND，不会静默成功。
每次发送先验证整批；成功序列严格是BEGIN→N个点→END。空批也发送BEGIN/END。单批最多2000点（协议库容量，不等于当前算法16点上限）。
24位批号分阵面维护，自动回绕。任何发送失败即停止，不为未完成批发送伪造结束帧，也不复用失败批号。
frames_accepted仅表示底层回调接受的帧数，不代表接收端已收到。
调用者须单线程拥有tx对象、保证输入点数组在同步调用期间不变；回调应有超时/有界队列，不可无限阻塞雷达处理线程。

## 下一步接硬件需要补的应用层

- 确认板上CAN控制器/外接控制器与收发器、总线映射和波特率后，实现回调。SDK can_send_frame可作为有对应驱动的板级适配接口，存在头文件不代表X2100板已有可用CAN。
- 在独立通信任务实现队列、背压/超时、总线错误恢复、控制字应用及周期调度。协议库当前是同步接口，不是完整CAN服务。
- 明确RCS、合成速度/方向和坐标约定，提供有效点数据。不能用0代替未知量。
- 与对端确认上述字段歧义，完成实机抓包对照。CAN固件升级另行实现和验收。
