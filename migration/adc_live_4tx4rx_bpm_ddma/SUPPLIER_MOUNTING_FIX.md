# 厂家航迹输出安装角开关修复（2026-09-29）

`Record_20260929_140651.dat` 的516帧（11548–12063）均包含一个检测点和航迹8。
点云输出约 (-1.7683, -0.0094) m，原始雷达坐标约 (1.77, 0.01) m；
航迹输出固定为 (2.125, 0.375) m。框中心与检测点不必重合，但两者方向不一致。

适配层通过 calloc/memset 初始化上下文，只设置了180度安装角，没有开启
`radarInfo.isCompInstallAng`。原2T4R初始化默认开启此开关。

检查厂家 libmmw_tracking.a 的 tracking_output.o：track_output 在 +0xb8
读取 ctx+92 的开关，为零时在 +0x118..+0x128 复制雷达坐标和航向；非零时
进入 +0x15c 分支，使用 ctx+96 的安装角旋转 X/Y、Vx/Vy，并调整航向。
因此修复为初始化时设置 isCompInstallAng=true，不在USB封包处再取负。
在180度下，位置和速度两轴都反号。保留厂家库的航向单位与原封包行为。

验证：主机测试检查首次及重复初始化后的开关/角度；交叉编译检查这两个
字段的32位ABI偏移。主机测试不执行厂家MIPS库，实际输出还需上板复测。
复测时在正前方和偏左/偏右各放单个目标，录普通DAT；比较同帧点云和航迹
应在原点同侧，再用移动目标检查速度方向。无需重新做幅相校准。
