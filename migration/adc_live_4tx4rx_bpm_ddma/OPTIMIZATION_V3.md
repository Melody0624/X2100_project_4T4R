# 四发 BPM DDMA 配置诊断和连续帧优化

本轮保持 4TX4RX、506 点、128 Chirp、26 us、50.328 ms 及原候选编码不变。
软件接口按四路共同 BPM 项建模；512 项码表、code 0 起点及逐帧复位已经确认，
逐 TX DDMA 相位/子带规则仍需厂家确认。没有加入 CAN、跟踪
或预警。旧 artifacts/bpm_ddma_4tx4rx_20260903 固件保留，新产物为
artifacts/bpm_ddma_4tx4rx_v3。

## 统一配置

radar_config.h 是编译期参数入口：ADC 布局、波形、FFT 尺寸、DDMA 子带偏移、
BPM 起点/帧复位、诊断等级、点云容量以及 DDMA 默认门限。
算法、合成 ADC、前端帧尺寸校验共用派生尺寸。effective_config.json 从编译后的
C 配置导出，打包清单包含该配置和源码 SHA256，不再另写一套波形数值。

当前实现只支持 506x128、4TX4RX、512 点 Range FFT、8 个 DDMA 子带和
连续偏移 0/1/2/3。其他维度会编译失败，其他子带排列会初始化失败。
统一配置不等于任意参数已经受支持。厂家已确认 BPM 最长 512 项、每帧从 code 0
重新开始；当前每帧 128 个 chirp 使用已核对码表的第 0～127 项。
启动检查有限正数、采样窗口能否放入 Chirp、Chirp burst 能否放入帧周期。
这只是必要条件，不能替代 ADC 启动延时、Ramp/idle、PLL/相位稳定时间检查。

## 联调诊断

radar_diagnostics_set_level(0/1/2) 必须在帧之间、处理任务内调用：

- 0：关闭扩展采样统计/打印；仍维护必要的帧序列及失败计数。
- 1（默认）：帧错误、输入间隔、处理耗时、缺号/重号/乱序/时间戳错误汇总。
- 2：增加四路 RX 最小/最大/均值/RMS/饱和/低位错误计数，以及幅度最强的
  四个 DDMA 单元的8子带幅度、最佳/次佳分数、空带幅度、状态和候选位图。

radar_diagnostics_get() 提供结构化快照，无需串口全图打印。单调用任务接口，
不保证多个任务并发读取时的原子性。强单元不等于独立目标，相邻单元可能来自
同一个目标；分数不是置信概率。详细统计会增加开销，需在板上分别测量。
默认每100个成功帧输出一次摘要，连续处理失败也按尝试次数限频。
已有帧级 pipeline_stats 和流级 stream 计数各自保留，不混用。

radar_pipeline_process_timed(payload, length, id, timestamp_us) 接收调用者提供的
采集帧号和单调时间戳。支持32位帧号回绕，拒绝重号、反向序号及时间戳回退，
清空旧点云；非法元数据不推进接收水位，合法元数据的坏payload消耗该帧号。
设备重启/数据源切换时，在处理任务内显式 radar_diagnostics_reset_stream()。
旧 radar_pipeline_process() 使用本地处理入口时间，板端目前使用软件递增ID，
所以其missing_ids不能证明传感器没有丢帧。32字节硬件Chirp头语义仍待厂家提供，
尚不能验证硬件帧号/码序号。恢复接口的单元测试不代表CSI故障已完成实机测试。

frame.error：0成功、1帧号异常、2时间戳异常、3长度/空指针、4配置、5ADC编码/饱和、
6处理失败。DDMA状态依次为0空、1已解析、2多解、3污染、4弱TX、5非法数值。

## 连续多帧与板端自测

默认 selftest 现在按150帧循环：0~39为+25m/s后退目标，40~49为空场景，
50~129为速度+2/-2m/s的双目标距离交叉，130~149为空场景，然后重新开始。
每帧距离按配置帧周期变化，添加独立噪声；每帧内部相干，帧间载波相位重置。
不能用该生成器验收跨帧载波相位相干处理。坐标仍是理想阵列，均非实采数据。
设置 RADAR_SELFTEST_SEQUENCE=0 可恢复固定首帧回放用于性能基线。

目标位置变化可在 MotorCycle Tools 的 USB 点云显示中观察，tracks仍为0。
算法PERF不含ADC合成时间；SIM-TIMING单独记录合成耗时；自测循环节拍同时计算
生成和处理耗时。合成器运行慢可能使模拟输入帧率下降，不等价于实采吞吐。
真实采集版仍由RF和阵列资料保护，缺资料时在SPI写入前停止。

## 验证

在WSL本目录执行 bash test_host.sh；SANITIZE=1 bash test_host.sh 运行内存检查。
原222用例继续验证ADC/FFT/DDMA/CFAR/AoA；新增test_stream包括：

- 配置非法值/采样窗口/帧周期/不支持布局/BPM周期拒绝。
- 诊断开关下输出逐字节一致；每RX统计与独立ADC扫描一致。
- 帧号回绕、缺帧、重复、乱序、时间戳回退、坏帧及恢复。
- 150连续帧、200目标匹配、30空帧，无旧点云残留；按帧切换诊断等级。

主机FFT替代MIPS NE10实现，测试耗时不是板端性能。板端需要上传新版串口日志，
检查CONFIG、SIM首帧PASS、DIAG、PERF以及USB断开/重连后的HOST计数。
