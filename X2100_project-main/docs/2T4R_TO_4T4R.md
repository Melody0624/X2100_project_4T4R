# 2T4R升级4T4R清单

## 当前基线

- Cheetah4401M芯片能力为4T4R。
- 当前MT-2T4R硬件、寄存器表、算法参数和标定均为2T4R。
- 仓库中没有可直接使用的4T4R寄存器表或完整工程。

## 硬件

1. 增加TX3/TX4射频匹配、天线和PCB布局。
2. 确认16通道虚拟阵列位置、间距和重排关系。
3. 重新评估隔离、电源、功耗和热设计。

## 雷达配置

1. 获取或生成Cheetah 4TX DDMA/BPM/TDM寄存器表。
2. 确定Chirp数量、空子带和相位编码。
3. 核对MIPI帧头、帧周期和速度分辨率。

## 软件

1. `numTxs`由2改为4。
2. 虚拟阵列和重排表由8项扩展至16项。
3. 角度窗和板级标定扩展至16个复通道。
4. Flash标定区由16个float扩展至32个float，并升级布局magic。
5. 修正6子带时Doppler FFT点数与子带宽计算顺序。
6. 更新EOL标定和上位机写参协议。

## 验证顺序

寄存器与ADC抓数 → 4TX子带分离 → 16通道相位检查 → CFAR点云 → 测角标定 → 性能和实时性测试。
