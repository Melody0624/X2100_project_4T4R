# 将文件系统中的固件更新到分区

本文基于**Freertos系统**。

## 一 支持的芯片和存储介质

​	update_nand命令支持nand flash 存储介质;

​	update_nor命令支持nor flash 存储介质;

​	update_mmc命令支持mmc flash存储介质。

​	update系列命令支持x1000、x1600、x2000、x2600、ad100系列芯片。

### 3.2 通过tftp网络协议传输

#### 3.2.1 准备PC端的环境

##### 3.2.1.1 安装tftpd-hpa

```
sudo apt-get install tftpd-hpa
```

##### 3.2.1.2 创建一个目录用于存放tftp文件

​	例如：	/home/fy/work/tftp

```
sudo mkdir /home/fy/work/tftp
sudo chmod 777 /home/fy/work/tftp
```

##### 3.2.1.3 配置tftp服务器

```
sudo gedit /etc/default/tftpd-hpa
修改TFTP_DIRECTORY="/home/fy/work/tftp"
```

##### 3.2.1.4 重启tftp服务

```
sudo systemctl restart tftpd-hpa
```

#### 3.2.2 设备端的配置选择
