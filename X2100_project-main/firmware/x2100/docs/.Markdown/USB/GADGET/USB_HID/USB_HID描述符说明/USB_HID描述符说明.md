| Offset | Field            | Size | Value | Description                                                  | Remark                                                       |
| ------ | ---------------- | ---- | ----- | ------------------------------------------------------------ | ------------------------------------------------------------ |

| 2      | bEndpointAddress | 1    | 81h   | 该描述符描述的USB设备上端点的地址                            | 地址编码如下：位0~3:端点号位4~6:保留，复位为零位7 :方向，被忽略    控制端点：         0:OUT端点         1:IN端点 |
