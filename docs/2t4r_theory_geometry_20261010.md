# 2T4R 用户八通道标定与实物阵列理论角度版

按用户要求关闭厂家角度映射表，改为按实际阵元间距生成理论角度。A 使用厂家新版检测库；B 保留检测、CFAR、测角、后处理源码，并保留启动窗函数空指针修复。两版继续使用用户提供的 TX0/TX1 × 4RX 八通道复数幅相补偿。

## 阵列依据

来源为用户提供的《天线相位中心坐标.docx》。文档列出从左到右的 RX 坐标 0、1.96、3.92、5.88 mm，以及 TX 坐标 7.8412、15.6812、23.5212、31.3612 mm。用户确认 TX1～4、RX1～4 的编号均从右到左；代码索引 TX0/RX0 对应实物 TX1/RX1。

本版启用最右侧的两路 TX，与现有八通道系数对应。虚拟阵元坐标按 TX 优先为：

| 通道 | 虚拟坐标 mm | 相对首通道 mm |
| --- | ---: | ---: |
| TX0RX0 | 37.2412 | 0 |
| TX0RX1 | 35.2812 | −1.96 |
| TX0RX2 | 33.3212 | −3.92 |
| TX0RX3 | 31.3612 | −5.88 |
| TX1RX0 | 29.4012 | −7.84 |
| TX1RX1 | 27.4412 | −9.80 |
| TX1RX2 | 25.4812 | −11.76 |
| TX1RX3 | 23.5212 | −13.72 |

有符号间距为 −1.96 mm；负号来自从右向左的通道排列。当前寄存器波形中心频率仍为 76.5 GHz，归一化间距约为 −0.500146004 波长。天线设计频率 76.8 GHz 未被用来替换当前发射波形频率。

角度映射采用 `asin(k/(128*d))`，k 为有符号 FFT 格子编号、d 为有符号归一化间距。公共坐标原点不影响测角。同步更新 `minElemSpacing[0]` 和八个 `vxPosn_sf1_azm`，系数仍按原 TX/RX 索引使用。

## 烧录包

共同目录：`artifacts/2t4r_tx01_8ch_compare_20261010/`。

- A：`A_vendor_new_theory/A_2T4R_theory_8ch.cfg`。
- B：`B_updated_source_theory/B_2T4R_theory_8ch.cfg`。

每个目录均提供独立 `zero_ota.bin`、厂家预编译 OTA SPL、烧录说明和构建校验记录。使用对应 CFG，核对 SPL、rtos_0、rtos_1 三个镜像路径来自同一版本目录。两版均为 2 MB NOR 的 A/B OTA 布局，`force_erase=1`，首次启动使用用户八通道默认系数；旧 Flash 参数和标定会清除。

波形保持 506 点、128 chirp、26.665 MS/s、16.699 MHz/μs、26 μs、50.328 ms，默认凯越输出，点云/航迹上限 256/32。安装角及输出坐标旋转逻辑沿用对应版本。

相对原来正间距的定义，角度正负方向会变化；请先用已知左、右位置确认上位机方向，再测试实际 0°、±15°、±30° 固定目标。理论映射用于排除厂家表的影响，不能保证幅相标定或实际板子不存在其他误差。

## 验证范围

验证最终 ELF 的用户八通道系数与实物阵元位置、理论映射开关、A/B 同一角度表生成代码、OTA 入口和容量、Flash 分区及输出哈希。B 的实际 SDK 初始化生成全部 128 个理论角度，并完成 6 组 ADC/RFFT/BPM/DFFT/DDMA/CFAR/AoA/后处理及内存池重建测试，使用 ASan/UBSan 和便携 FFT。检测库、板上 SIMD、CRT 和真实 USB 未通过这些主机测试覆盖，尚需烧录实测。

复现编译：`tools/build_2t4r_tx01_compare.sh A_vendor_new_theory` 或 `B_updated_source_theory`。
